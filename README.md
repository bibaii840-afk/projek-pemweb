KampusEvent
Website informasi dan pendaftaran event kampus (seminar, lomba, dan workshop) dalam satu tempat. Dibuat sebagai projek mata kuliah Pemrograman Web.

Fitur
- Daftar event dalam bentuk kartu berisi poster, judul, tanggal, sisa kuota, dan status (Tersedia / Penuh).
- Filter kategori (Semua, Seminar, Lomba, Workshop) dan pencarian event berdasarkan judul.
- Form pendaftaran dengan validasi nama, NIM, dan email.
- Kuota otomatis: kuota berkurang setiap ada pendaftaran, dan pendaftaran ditutup jika kuota habis.
- Pilihan event otomatis saat pengguna menekan tombol "Daftar" pada kartu (id event dibawa lewat URL).
- Responsif untuk mobile, tablet, dan desktop, dengan menu hamburger di layar kecil.
- Aksesibilitas dasar: label form, aria-current, aria-pressed, aria-expanded, indikator fokus keyboard, dan dukungan prefers-reduced-motion.

Teknologi
- HTML5 (semantik)
- CSS3 (CSS variables, Flexbox, CSS Grid, media query)
- JavaScript (DOM, event listener, array of objects, perulangan, percabangan)
